# Фаза 5 — Маркетплейс

## Цель
Площадка купли-продажи скинов CS2 между пользователями.

---

## Задачи

### 5.1 API модуль маркетплейса

```js
// src/api/market.api.js
import api from './axios';

export const marketApi = {
  getListings: (params) => api.get('/market', { params }),
  getListing: (id) => api.get(`/market/${id}`),
  buy: (id) => api.post(`/market/buy/${id}`),
  sell: (data) => api.post('/market/sell', data),
  cancel: (id) => api.delete(`/market/${id}`),
  getPriceHistory: (skinId) => api.get(`/market/price-history/${skinId}`),
};
```

### 5.4 Расширенные фильтры (MarketFilters)

| Фильтр | Тип | Описание |
|---|---|---|
| Поиск | Text + debounce | По названию скина |
| Категория оружия | Checkbox-группа | Винтовки, Пистолеты, ПП, Дробовики, Ножи, Перчатки |
| Конкретное оружие | Dropdown | AK-47, M4A4, AWP... (зависит от категории) |
| Редкость | Checkbox-группа | С цветовыми индикаторами |
| Состояние | Checkbox-группа | FN, MW, FT, WW, BS |
| Цена | Range slider | С min/max инпутами |
| StatTrak | Toggle | Вкл/Выкл/Все |
| Сортировка | Select | Цена ↑/↓, Дата, Популярность, Float |

**URL-синхронизация:** Фильтры синхронизируются с URL через `searchParams` — позволяет делиться ссылкой с фильтрами.

### 5.6 Процесс покупки

1. Клик «Купить»
2. Модалка подтверждения:
   - Превью скина
   - Цена
   - Текущий баланс → баланс после покупки
   - Кнопка «Подтвердить покупку»
3. Запрос на API
4. Оптимистичное обновление:
   - Баланс уменьшается
   - Скин появляется в инвентаре
   - Toast: «AK-47 | Vulcan куплен!»
5. Если недостаточно средств:
   - Toast с ошибкой
   - Кнопка «Пополнить баланс»

### 5.8 История цен (PriceHistory)

Простой линейный график цены скина за последний период:
- Используем **Recharts** или рисуем SVG вручную
- Показываем: 7 дней / 30 дней / Все время
- Средняя, минимальная, максимальная цена

```bash
npm install recharts  # опционально, для графиков
```

### 5.9 Мои лоты (вкладка)

На странице маркетплейса — вкладка «Мои лоты»:
- Список выставленных скинов
- Статус: «На продаже» / «Продан»
- Кнопка «Снять с продажи»
- Дата выставления
- Просмотры (если API поддерживает)
