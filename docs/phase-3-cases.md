### 3.5 ⭐ Анимация рулетки (CaseRoulette) — КЛЮЧЕВАЯ ФИЧА

#### Принцип работы

1. **Подготовка ленты** — генерируется массив ~50-80 скинов (повторяющихся из содержимого кейса, с учётом вероятностей)
2. **Результат от сервера** — API возвращает выигранный скин, клиент вычисляет его позицию в ленте
3. **Анимация** — лента прокручивается горизонтально с easing (быстро → замедление)
4. **Остановка** — указатель (стрелка сверху) останавливается на выигранном скине
5. **Результат** — модалка с выигрышем + эффекты

#### Технические детали

```jsx
// src/components/case/CaseRoulette.jsx
// Ключевые состояния:
// - idle: ожидание клика
// - spinning: анимация прокрутки
// - result: показ результата

// Параметры анимации:
const ROULETTE_CONFIG = {
  ITEM_WIDTH: 160,          // Ширина элемента в px
  ITEMS_COUNT: 60,          // Кол-во элементов в ленте
  SPIN_DURATION: 5000,      // Длительность прокрутки в ms
  WINNING_POSITION: 45,     // Позиция выигрыша (ближе к концу)
  EASING: 'cubic-bezier(0.17, 0.67, 0.12, 0.99)',  // Замедление
};
```

#### Алгоритм анимации

```
1. Пользователь нажимает "Открыть"
2. Запрос на API → получаем wonSkin
3. Генерируем ленту из ~60 скинов:
   - Первые ~44 — рандомные из содержимого (с учётом вероятностей)
   - Позиция 45 — выигрышный скин (wonSkin)
   - Остальные — снова рандомные
4. Запускаем CSS transition / Framer Motion animate:
   - translateX: 0 → -(ITEM_WIDTH * WINNING_POSITION - containerCenter + randomOffset)
   - duration: 5s
   - easing: cubic-bezier (быстрый старт, плавное замедление)
5. Звуковой тик при прохождении каждого элемента
6. По завершении — показываем результат
```

#### Звуковые эффекты

```js
// src/hooks/useSound.js
// Звуки:
// - tick.mp3    — тик при прокрутке (каждый элемент)
// - win-low.mp3  — выигрыш обычного скина
// - win-mid.mp3  — выигрыш среднего (Restricted+)
// - win-high.mp3 — выигрыш редкого (Covert / Gold)
```

#### CSS для рулетки

```css
/* Контейнер с overflow: hidden */
.roulette-container {
  @apply relative overflow-hidden rounded-xl border-2 border-base-300;
  height: 200px;
}

/* Указатель (стрелка сверху) */
.roulette-pointer {
  @apply absolute top-0 left-1/2 -translate-x-1/2 z-10;
  width: 2px;
  height: 100%;
  background: linear-gradient(to bottom, #FFD700, transparent);
}

/* Лента скинов */
.roulette-tape {
  @apply flex items-center h-full;
  transition: transform var(--spin-duration) var(--spin-easing);
}

/* Элемент ленты */
.roulette-item {
  @apply flex-shrink-0 flex flex-col items-center justify-center p-2;
  width: 160px;
  border-left: 1px solid rgba(255,255,255,0.1);
}

/* Свечение выигрышного элемента */
.roulette-item.winner {
  @apply animate-glow-pulse;
  box-shadow: 0 0 30px var(--rarity-color);
}
```

```
┌────────────────────────────┐
│          🎉 ВЫ ПОЛУЧИЛИ!   │
│                            │
│      [Изображение скина]   │
│                            │
│    AK-47 | Vulcan          │
│    Factory New (0.032)     │
│    ═══🟣 Restricted ═══   │
│                            │
│    💰 Стоимость: 2,450     │
│                            │
│  [В ИНВЕНТАРЬ]  [ПРОДАТЬ]  │
│  [ОТКРЫТЬ ЕЩЁ]            │
└────────────────────────────┘
```

**Эффекты по редкости:**
| Редкость | Эффект |
|---|---|
| Consumer — Mil-Spec | Простое появление |
| Restricted | Мягкое свечение |
| Classified | Яркое свечение + пульсация |
| Covert | Свечение + частицы |
| Gold (Нож) | Конфетти + вспышка + специальный звук |

### 3.7 Просмотр содержимого (CaseContents)

Сетка скинов, которые могут выпасть из кейса:
- Группировка по редкости
- Hover — показ названия и шанса
- Визуальная полоска вероятностей

### 3.8 Мультиоткрытие (x3, x5)

- Показываем 3 или 5 рулеток одновременно (вертикально стекированные или последовательно)
- Каждая крутится с небольшой задержкой (200ms между стартами)
- Общий результат показывается в модалке со списком всех дропов

### 3.9 Быстрое открытие

- Кнопка «⚡ Быстро» — пропуск анимации
- Результат показывается сразу с fade-in эффектом
