# SOUL.md: дизайн-принципы GOLDEN-DROP

Этот файл читают все, кто делает интерфейс (и люди, и ИИ-помощники). Если решение по дизайну не описано здесь, выбирай то, что делает страницу понятнее и быстрее.

## 1. Что это за продукт

GOLDEN-DROP: кейсы, рулетка и маркетплейс скинов CS2. Человек приходит сюда за двумя вещами: открыть кейс и выгодно продать или купить скин. Дизайн должен помогать с этим, а не мешать.

Ориентир: интерфейс самой CS2 и Steam Market. Плотный, чёткий, без лишнего. Тёмная тема, потому что так привычно игрокам, но не «киберпанк ради киберпанка».

## 2. Что мы НЕ делаем (чтобы не выглядело сгенерированным)

- Нет фиолетово-розовых градиентов и неона по всему экрану.
- Нет свечения у каждого элемента. Свечение (glow) только у предмета высокой редкости и только вокруг самого предмета.
- Нет эмодзи в заголовках и кнопках. Иконки только SVG, из одного набора, одной толщины линии.
- Нет сетки из одинаковых скруглённых карточек со светло-серой тенью везде.
- Нет подписи КАПСОМ над каждым заголовком и нет нумерации «01 / 02 / 03», если это не реальные шаги.
- Нет «fade-in + slide-up» у каждого блока при прокрутке и нет hover-анимации у каждой карточки.
- Нет текстов вроде «Откройте для себя будущее трейдинга». Пишем по делу.

## 3. Цвет

Фон спокойный, тёмный, нейтральный (чуть холодный графит), не синий и не фиолетовый.

| Роль | Цвет | Где использовать |
|---|---|---|
| Фон страницы | `#13151A` | body |
| Панель | `#1B1E25` | шапка, боковые панели, карточки |
| Панель выше | `#232731` | выпадающие меню, модалки |
| Линия | `#2D323D` | границы, разделители |
| Текст | `#E8EAEE` | основной текст |
| Текст приглушённый | `#8C93A1` | подписи, второстепенное |
| Акцент | `#E8A33D` | главные кнопки, активный пункт меню, фокус |
| Плюс | `#3FB67A` | пополнение, выигрыш |
| Минус | `#E5534B` | списание, ошибка |

Правила:
1. **Акцент один.** Янтарный только для действий (кнопки, активное состояние). Больше им ничего не красим.
2. **Цвета редкости CS2 живут только на предметах** (рамка, полоска снизу, фон при открытии). Ими нельзя красить кнопки, заголовки и фон страниц.
3. Зелёный и красный только для денег и статусов.

Цвета редкостей (из игры, не менять):

| Редкость | Цвет |
|---|---|
| Consumer | `#B0C3D9` |
| Industrial | `#5E98D9` |
| Mil-Spec | `#4B69FF` |
| Restricted | `#8847FF` |
| Classified | `#D32CE6` |
| Covert | `#EB4B4B` |
| Rare Special (нож, перчатки) | `#FFD700` |

Эти цвета можно подкрутить по яркости для читаемости на тёмном фоне, но оттенок должен оставаться узнаваемым.

## 4. Типографика

- Заголовки: **Barlow Condensed** (600), узкий шрифт, как на табло в игре.
- Текст и интерфейс: **IBM Plex Sans** (400, 500, 600).
- Цены, баланс, float: цифры с `font-variant-numeric: tabular-nums`, чтобы не прыгали при изменении.
- Размеры: 12 / 14 / 16 / 20 / 28 / 40. Лишние размеры не вводим.
- Длина строки текста не больше 70 символов.

Подключение (Google Fonts):
```html
<link href="https://fonts.googleapis.com/css2?family=Barlow+Condensed:wght@600&family=IBM+Plex+Sans:wght@400;500;600&display=swap" rel="stylesheet">
```

## 5. Форма и компоненты

- **Скругления:** 4 px у кнопок и полей, 8 px у панелей. Не один радиус на всё.
- **Тени:** почти нет. Уровни показываем цветом панели (см. таблицу) и линиями.
- **Карточка скина:** картинка, название, цена. Float и кнопка действия появляются при наведении или нажатии. Внизу карточки цветная полоска редкости (3 px), рамка и фон нейтральные.
- **Кнопки:** главная (янтарная, одна на экран), вторичная (контур), опасная (красная, только для необратимых действий). Названия кнопок говорят действие: «Открыть кейс», «Выставить на продажу», «Забрать». Не «Отправить» и не «ОК».
- **Wear bar:** тонкая шкала от Factory New до Battle-Scarred с отметкой значения float.
- **Таблицы и списки** (маркет, история) выровнены по левому краю, цифры по правому.

## 6. Рулетка и анимация

Анимация нужна там, где она что-то объясняет. Остальное без движения.

- **Рулетка:** быстрый старт, плавное замедление по `cubic-bezier(0.17, 0.67, 0.12, 0.99)`, 5-7 секунд. Указатель по центру. Звук «щелчка» на каждом предмете (с кнопкой Mute).
- **Результат:** выпавший предмет увеличивается и остаётся по центру. Для Covert и Rare Special добавляем одну вспышку цвета редкости и конфетти. Для обычных дропов никаких эффектов, только предмет.
- **Баланс:** число плавно меняется (count-up или count-down) и коротко подсвечивается зелёным или красным.
- **Загрузка:** скелетоны вместо спиннеров. Кнопка при нажатии сразу показывает состояние «Открываем…».
- Если у пользователя включено `prefers-reduced-motion`, рулетка просто показывает результат без прокрутки.

## 7. Честность и ясность

- Шансы выпадения видны под каждым кейсом (полоска по редкостям + проценты).
- Float показываем всегда, с шкалой.
- При выставлении скина на продажу сразу показываем: цена, комиссия, сколько придёт на баланс. Без сюрпризов.
- Ошибки пишем по делу: что случилось и что сделать. «Недостаточно средств. Пополните баланс на 12,50 $» вместо «Что-то пошло не так».

## 8. Страницы и переходы

- Шапка одинаковая на всех страницах: логотип, разделы (Кейсы, Маркет, Инвентарь), баланс, профиль.
- Активный раздел отмечен акцентом и подчёркиванием.
- Переход между страницами мгновенный. Если данные грузятся, показываем скелетон, а не пустой экран.
- Кнопка «Назад» в браузере всегда работает ожидаемо.

## 9. Мобильная версия

Сначала телефон, потом десктоп.
- Нижняя панель навигации вместо верхнего меню.
- Кнопки не меньше 44 px по высоте.
- Рулетка вертикальная или горизонтальная, но всегда помещается в экран без прокрутки страницы.
- Фильтры маркета открываются отдельной панелью снизу.

## 10. Минимум качества

Перед тем как отправить код, проверь:
- [ ] Видно фокус при навигации с клавиатуры.
- [ ] Текст читается (контраст не ниже 4.5:1).
- [ ] Всё работает на экране 375 px шириной.
- [ ] Звук можно выключить одним нажатием.
- [ ] Нет эффекта, который можно убрать без потери смысла.
